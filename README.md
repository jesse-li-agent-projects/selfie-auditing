## Research questions

These are the standing high-level questions for this project.

1. Will a SelfIE adapter correctly uncover something the model is actively hiding?
2. How does performance differ if the model is control / prompted / fine-tuned   to complete its task?
3. How does performance differ if the SelfIE adapter is trained on the model being tested (as might be more realistic if we're trying to use this to detect a misaligned model), instead of the base model?
